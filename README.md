# Mapa-EM
Herramienta para crear mapas interactivos de estudios de mercado a partir de un excel subido.

## Uso rápido

1. Descarga o clona este repositorio.
2. Abre `index.html` en tu navegador preferido.
3. Carga un archivo Excel (`.xlsx` o `.xls`) con la hoja `EEMM`.
4. Explora el mapa y ajusta los filtros desde el panel lateral derecho.

> No es necesario ningún paso de compilación: toda la lógica está implementada en JavaScript puro con dependencias CDN.
